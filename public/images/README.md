# Photos

Drop these in and they appear immediately — no code change. Until then the site
shows a labelled placeholder at exactly the right size, so the layout never shifts.

| file | where it shows | best size |
| --- | --- | --- |
| `portrait.jpg` | Hero — the large framed portrait | 900 × 1125 (4:5) |
| `work-1.png` | Hero — small tile 1 | 500 × 500 |
| `work-2.png` | Hero — small tile 2 | 500 × 500 |
| `work-3.png` | Hero — small tile 3 | 500 × 500 |
| `about.jpg` | About — wide working shot | 1200 × 750 (16:10) |

File names are set in `media` at the top of `src/data/portfolio.ts` — change them
there if you'd rather use different ones.
