# Logo drop-box

Drop a file here named after the slug and it replaces that tile everywhere —
in the cards, in the chips, and on the floating tiles in the 3D scene.
`.svg` is best; `.png` and `.webp` also work. Square, transparent, ~256px.

    public/logos/bajaj-finance.svg   →  replaces the  BF  tile
    public/logos/magadh-iron.png     →  replaces the  MI  tile

## Adding a brand that isn't listed

Open `src/lib/brand.ts` and add a line to `SEEDS`:

```ts
{ names: ['My Company'], slug: 'my-company', color: '#22d3ee', initials: 'MC' },
```

Then drop `public/logos/my-company.svg` in here.
